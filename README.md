# Demos

Interactive learning activities built live during Codaptive Labs workshops. Each one is a
single HTML file made with Activity Studio. It runs on its own and embeds in a Canvas page.

## Open one

Every file here is live at:

```
https://codaptive-labs.github.io/demos/<file-name>.html
```

## Make your own

- **Activity Builder** walks you through it with any AI chat tool, then hands you the embed
  code: https://codaptivelabs.com/apps/activity-builder.html
- **Activity Studio**, the full skill for Claude and other agent tools, is in the Codaptive
  Labs Skill Library: https://codaptivelabs.com/skills
- **Hosting your own:** an activity needs a home on the web before Canvas can show it. A free
  GitHub Pages site like this one works. The steps are in the
  [hosting guide](https://github.com/codaptive-labs/skills/blob/main/skills/activity-studio/references/hosting-and-embedding.md).

## About these files

These are workshop demos, so they come and go. For a steady set of examples of every
activity type, see the gallery: https://codaptive-labs.github.io/activities/
